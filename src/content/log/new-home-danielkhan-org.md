This site has moved to **danielkhan.org**. Old `danielkhan26.github.io` links forward automatically to the same page here.

## What changed behind the scenes

- **Speed:** pages are served from Cloudflare's network close to each visitor, and files that never change are cached for a year, so repeat visits load almost instantly.
- **Security:** every response carries strict HTTP security headers, HTTPS is enforced everywhere, and `www.danielkhan.org` redirects here.
- **Still free and still private:** there are no cookies, trackers or ads. The only cost is the domain itself.

The code behind all of this is in the [free template](/workshop/portfolio-template/), including the deployment setup.
