A documentary narrator can sound forceful without shouting, and conversational without improvising facts. The hard part is keeping the logical shape of a researched argument once it becomes speech.

This lab develops a repeatable route from evidence file to finished video: spoken script, teleprompter rehearsal, camera recording and review.

## From script to voice

A reader can return to the start of a long sentence; a listener cannot. So each paragraph is rehearsed to check that it is understood on the first hearing. Words that carry meaning are marked, pauses come before a second interpretation, and sentences that only repeat what the audience already knows are cut.

The spoken script holds only the words to be said. Charts, sources and production cues live in a separate production copy, so the performance stays clean and the evidence stays checkable.
